# 💅 Kerri Nails — MVP

Полноценное веб-приложение для маникюрного салона.  
Фронтенд на **React + TypeScript + Tailwind CSS**, бэкенд на **Node.js + Express**.  
Вместо базы данных используются обычные **JSON-файлы** — никакой установки PostgreSQL не нужно.

## 🚀 Запуск проекта с нуля

### Шаг 1 — Убедитесь, что установлен Node.js

Откройте командную строку (Терминал / CMD / PowerShell) и введите:

```bash
node -v
```

Должно показать что-то вроде `v18.x.x` или `v20.x.x`.  
Если Node.js не установлен — скачайте с [nodejs.org](https://nodejs.org) (кнопка **LTS**).

---

### Шаг 2 — Установите зависимости бэкенда

```bash
cd kerrinails-mvp/backend
npm install
```

> Это скачает Express, JWT, bcrypt и другие пакеты.

---

### Шаг 3 — Создайте аккаунт администратора

```bash
node create-admin.js
```

В консоли появится:
```
✅ Администратор создан!
   Email: admin@kerrinails.ru
   Пароль: admin123
```

> ⚠️ После первого входа смените пароль — это важно для безопасности!

---

### Шаг 4 — Запустите бэкенд

```bash
npm run dev
```

Должно появиться:
```
Server running on http://127.0.0.1:5000
```

> Оставьте это окно открытым! Бэкенд должен работать параллельно с фронтендом.

---

### Шаг 5 — Установите зависимости фронтенда

Откройте **новое** окно терминала:

```bash
cd kerrinails-mvp/frontend
npm install
```

---

### Шаг 6 — Запустите фронтенд

```bash
npm run dev
```

Должно появиться:
```
  VITE v5.x.x  ready in 500ms
  ➜  Local:   http://localhost:5173/
```

---

### Шаг 7 — Откройте браузер

Перейдите по адресу: **http://localhost:5173**

🎉 Готово! Сайт работает.

## 📞 Формы обратной связи

На любой странице справа плавают 2 кнопки:
- 📞 **Заказать звонок** — клиент оставляет имя и телефон
- ✉️ **Написать нам** — клиент пишет сообщение

Форма открывается плавно сбоку, адаптирована для мобильных.

> Чтобы письма реально отправлялись на email — подключите EmailJS:  
> 1. Зарегистрируйтесь на [emailjs.com](https://emailjs.com)  
> 2. Создайте сервис и шаблон  
> 3. В файле `frontend/src/components/forms/ContactPanel.tsx` раскомментируйте строку с `emailjs.send(...)` и вставьте свои ключи

## 🔑 Как работает авторизация

- Клиент **регистрируется** → данные сохраняются в `backend/data/users.json`
- При входе сервер выдаёт **JWT-токен** (как ключ доступа)
- Токен хранится в браузере и отправляется с каждым запросом
- Токен действует **7 дней**, потом нужно войти снова

## 💾 Где хранятся данные

Все данные — в обычных JSON-файлах:

| Файл | Что хранит |
|------|-----------|
| `backend/data/users.json` | Аккаунты клиентов и администраторов |
| `backend/data/appointments.json` | Все записи на услуги |

> Файлы создаются автоматически при первом запуске. Не удаляйте их!

## 🛠 Как изменить услуги или портфолио

Откройте файл:
```
frontend/src/utils/data.ts
```

Там два массива:

**SERVICES** — услуги (название, цена, описание, фото):
```ts
{ id: 1, name: 'Классический маникюр', price: 1500, description: '...' }
```

**PORTFOLIO_ITEMS** — работы в портфолио:
```ts
{ id: 1, img: nails, category: 'manicure', title: 'Нюдовый маникюр' }
```

Чтобы добавить новое фото — положите его в `frontend/src/assets/` и импортируйте в начале файла.

## 📋 Управление записями (Admin Panel)

1. Войдите как администратор
2. Перейдите на `/admin`
3. Доступные действия:
   - **Подтвердить** — клиент получает статус «Подтверждена»
   - **Завершить** — статус меняется на «Завершена»
   - **Отменить** — запись отменяется
4. Фильтрация записей по статусу
5. Вкладка «Статистика» — сводка по всем записям

## ⚙️ Если что-то не работает

**Проблема: бэкенд не запускается**
```bash
# Убедитесь, что вы в папке backend
cd kerrinails-mvp/backend
npm install
node server.js
```

**Проблема: порт 5000 занят (Windows)**
```bash
netstat -ano | findstr :5000
taskkill /PID <номер> /F
```

**Проблема: порт 5000 занят (Mac/Linux)**
```bash
lsof -ti:5000 | xargs kill
```

**Проблема: фронтенд пишет ошибку сети**  
Убедитесь, что бэкенд запущен и работает на `http://127.0.0.1:5000`
